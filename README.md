# ДТЭК → Telegram

Cloudflare Worker принимает команды и кнопки Telegram сразу и хранит выбранные адреса для каждого чата. В группе выбор общий. Каждые пять минут Cloudflare запускает GitHub Actions: Chromium получает данные ДТЭК, затем Worker отправляет уведомления только при изменении статуса, графика или экстренного режима. Ноутбук для работы не нужен.

## Команды

- `/start` — открыть выбор адресов. Отметьте один или несколько и нажмите «Сохранить выбор».
- `/addresses` — изменить выбор.
- `/status` — показать последние результаты и запросить свежую проверку.
- `/stop` — отключить уведомления для этого чата.

В группе используйте команды с именем бота: `/start@имя_бота`, `/status@имя_бота`, `/addresses@имя_бота`, `/stop@имя_бота`. Боту нужно право отправлять сообщения. Меню может менять участник, который его открыл; изменения сохраняются для всей группы.

Кнопки отвечают сразу, а проверка источника занимает несколько минут и зависит от очереди GitHub. Данные старше 12 минут отмечаются как устаревшие. Неизменившийся результат не создаёт повторного уведомления; явный запрос `/status` получает свежий ответ даже без изменений.

## Развёртывание

Порядок подключения и переноса подписок описан в [worker/DEPLOY.md](worker/DEPLOY.md). Не переключайте Telegram на webhook, пока Worker, его секреты и новый workflow не настроены.

GitHub Actions использует Secrets `DTEK_ADDRESSES_JSON`, `WORKER_URL`, `WORKER_SECRET`. Cloudflare использует `TELEGRAM_BOT_TOKEN`, `DTEK_ADDRESSES_JSON`, `STATE_KEY`, `WORKER_SECRET`, `WEBHOOK_SECRET`, `GITHUB_DISPATCH_TOKEN`. Последний токен должен иметь только Actions write для этого репозитория; обновляйте его до истечения срока действия. Адреса и токены в файлы репозитория не добавляются.

Подписки хранятся в Durable Object Cloudflare. Ветка `bot-state` содержит зашифрованный снимок прежней версии для переноса, защищённый AES-256-GCM. Рабочий workflow имеет только право чтения содержимого репозитория и не получает Telegram-токен. Старый polling `src/run.cjs` с действующим webhook запускать нельзя.

Локальная проверка: `npm ci` и `npm test`. Для загрузки Worker требуется Node 22+ и Wrangler; конфигурация находится в `worker/wrangler.jsonc`.

## Что означает статус

ДТЭК предоставляет график и объявления об отключениях. «По графику — свет предусмотрен» означает ожидаемое снабжение, а не измерение электричества в доме. Периоды без света перечисляются явно. При экстренных отключениях бот предупреждает, что график может не действовать; неизвестный результат не считается подтверждением восстановления графика.

Недоступность ДТЭК показывается как отсутствие актуальных данных. Такие проверки могут завершаться ошибкой в Actions, при этом Cloudflare продолжает принимать команды. Telegram и сохранение состояния не образуют общей транзакции: после редкого сбоя доставки или хранения возможно повторное сообщение.
